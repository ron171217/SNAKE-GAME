# Snake Game

A modern, responsive take on the classic Snake arcade game. Guide the neon snake across a glassy game board, collect glowing fruit, and set new high scores as the pace ramps up.

## Features

- Sleek, responsive UI with keyboard, touch, and on-screen controls
- Dynamic speed increase after each fruit for escalating challenge
- Local high score tracking with instant scoreboard updates
- Pause/resume support plus automatic pausing on tab change
- Accessible overlays and live score announcements

## Getting Started

1. Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari).
2. Press `Start` or tap a direction to begin playing.

## Controls

- **Keyboard:** Arrow keys or `WASD`
- **Touch:** Swipe across the canvas
- **On-screen pad:** Tap the directional arrows (center button toggles pause)
- **Pause/Resume:** `Pause` button, `Esc` key, or pad center button
- **Reset:** `Reset` button restores the board and high score display

## Project Structure

- `index.html` – Application layout and UI controls
- `styles.css` – Styling, responsive layout, and theming
- `script.js` – Game loop, rendering, and input logic
